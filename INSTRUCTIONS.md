# Services Used

All dynamic stats are **generated inside this repo by GitHub Actions** — no
rate-limited public API is hit when someone views the profile.

| What | Source | How it's served |
|------|--------|-----------------|
| Typing header/footer | [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg) | `readme-typing-svg.demolab.com` (the old `herokuapp.com` domain is deprecated) |
| Profile views counter | [komarev/ghpvc](https://github.com/antonkomarev/github-profile-views-counter) | External, lightweight, reliable |
| Social badges | [Shields.io](https://shields.io) | External, reliable |
| Skill icons | [Skill Icons](https://github.com/tandpfun/skill-icons) | Static CDN, reliable |
| Contribution snake | [Platane/snk](https://github.com/Platane/snk) | Generated by the `Generate Snake` action → `output` branch |
| Stats / languages / productive-time cards | [github-profile-summary-cards](https://github.com/vn7n24fzkq/github-profile-summary-cards) | Generated by the `GitHub-Profile-Summary-Cards` action → `profile-summary-card-output/` on `main` |

> **Why no github-readme-stats / streak-stats?** The public
> `github-readme-stats.vercel.app` instance is paused (returns 503:
> `DEPLOYMENT_PAUSED`) and `streak-stats.demolab.com` is frequently
> rate-limited, which made the cards render as errors or broken images.
> Self-generated cards never have this problem.

# Setup / Maintenance

1. This repo must be named `<your-username>` (a GitHub profile repository).
2. Both workflows carry `permissions: contents: write`, so the built-in
   `GITHUB_TOKEN` can push — no PAT or repo-settings change required.
3. On first setup (or if the images ever look stale/broken), go to the
   **Actions** tab and manually run:
   - `Generate Snake` — regenerates the contribution snake (then auto-runs every 12h).
   - `GitHub-Profile-Summary-Cards` — regenerates the stat cards (then auto-runs daily).
4. **Note:** GitHub disables scheduled workflows after ~60 days without repo
   activity. If the stats freeze, re-enable them from the Actions tab (or push
   any commit).
5. The stat cards use the `github` (light) and `github_dark` themes via
   `<picture>` tags, so they follow the viewer's GitHub theme. To change
   themes, swap the folder names in the README's Stats section — every theme
   in `profile-summary-card-output/` is generated on each run.
6. `Resume.pdf` in the repo root is linked from the README — replace the file
   to update the resume, no README change needed.
